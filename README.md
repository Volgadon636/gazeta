# gazeta

Каждое утро (07:07 МСК) GitHub Actions собирает вчерашние посты из каналов в `channels.txt`
через публичные страницы `t.me/s/<канал>` и кладёт их в `latest.md` и `posts/<дата>.md`.
Затем запланированная задача Claude читает `latest.md` и присылает «газету».

- Добавить или убрать канал: отредактировать `channels.txt`.
- Запустить вручную: Actions → collect → Run workflow.
